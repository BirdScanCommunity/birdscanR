# Default class abbreviations table of the birdscanR package

Table to allow for easy abbreviations of the standard classes of the
Birdscan MR1.

## Usage

``` r
data(classAbbreviations)
```

## Format

An object of class `data.frame`.

## See also

Other sample data:
[`loadManualBlindTimes()`](https://birdscancommunity.github.io/birdscanR/reference/loadManualBlindTimes.md),
[`manualBlindTimes`](https://birdscancommunity.github.io/birdscanR/reference/manualBlindTimes.md)
